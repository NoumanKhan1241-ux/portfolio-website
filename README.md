# Portfolio — Starter Scaffold

This is a starter single-page portfolio scaffold (Vanilla HTML/CSS/JS) with animation hooks for GSAP, Three.js, and Lottie.

Files created:
- `index.html` — single-page entry with header, hero, intro, projects, services, skills, contact, footer.
- `styles/style.css` — base styles and layout.
- `scripts/main.js` — basic GSAP scroll reveals and hero visual placeholder.
- `assets/` — place your images, `resume.pdf`, and Lottie JSONs here.

Quick start:
1. Open `index.html` in a browser for local testing.

Deploy to Vercel:
- Create a Git repo in this folder and push to GitHub.
- Import the repo on Vercel and set the framework to "Other" (static site). Vercel will deploy `index.html`.
